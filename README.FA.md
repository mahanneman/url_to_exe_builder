## 📋 نیازمندی‌ها

- **ویندوز**
- **پایتون ۳.۸ یا بالاتر** (اگر از سورس اجرا می‌کنید)
- **PyInstaller** (`pip install pyinstaller`)
- اختیاری: **Pillow** (در صورت نیاز برای تبدیل آیکون به‌صورت خودکار نصب می‌شود)
